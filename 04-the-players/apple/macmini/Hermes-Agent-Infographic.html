🎯 What is Hermes?

Hermes is a local-first AI agent framework built by Nous Research. It bridges natural language inputs to executable actions across your machine, leveraging Apple Silicon MLX hardware acceleration for privacy-preserving, offline-capable intelligence.

Model: Qwen3.5-4B (4-bit MLX quantized)

Backend: llama.cpp / MLX runtime

Platform: macOS 14+ (Apple Silicon M1/M2/M3/M4)
