🌀 How Hermes Agent Works

Visual workflow guide for the Qwen3.5-4B-MLX-4bit model

1
You Speak
You provide a request in natural language.
Example: "Build a dashboard for Home Assistant" or "Debug my HA integration"

🧠 Qwen3.5-4B-MLX-4bit

The model interprets your intent and plans the task

3
Tool Descriptor
tool_describe() loads the JSON schema for each tool:
tool_call(calls=[{\"name\": \"python-debugpy\", ...}, \ {\"name\": \"web_search\", ...}])
✅ Validates parameters against schemas
✅ Returns tool names, descriptions, parameters
5
Capability Selection
The tool call system routes to the appropriate 18+ tool categories:

🔍 Browser

web_search, web_extract, browser_exec, blocked-page-recovery

💻 DevTools

codebase-inspection, python-debugpy, node-inspect-debugger, terminal

📊 Productivity

xlsx, powerpoint, docx, google-workspace, meeting-action-items

🎨 Creative

architecture-diagram, popular-web-designs, manim-video, p5js

📧 Connectors

manage_connections (Gmail, Notion, Linear MCP servers)

🤖 Multi-Agent

claude-code, opencode, computer_use (autonomous-ai-agents)

7
Tool Execution Loop
Tool Call → Python/ECLI → Result
tool_call(calls=[{"name": "terminal", "arguments": {"command": "node script.js"}}])
- Browser tools: Execute in sandboxed context
- Terminal tools: Direct shell commands
- Output captured and returned to model
9
Memory & Skills
Results inform:
  • Skill: Create/procedure for recurring tasks (e.g., `home-assistant-setup`)
  • Memory: Store high-signal facts across sessions
skill_manage(name='home-assistant-setup', action='create') memory(target='memory', content='HA uses MQTT port 4567')
11
You Get Results
Deliverables: Files, markdown, data, or direct terminal output

📁 Files

MEDIA:/ (files, images, audio, video)

📊 Data

xlsx, markdown, JSON

🎨 Visual

HTML files with ::preview{file="guide.html"}

🔊 Audio

text_to_speech for voice responses

13
Iterate & Optimize
User feedback → refine intent → adaptive workflow
- Skills loaded first (skill_view) for precision
- Parallel tool calls for performance
- Notifications for long-running tasks
- Error recovery with retries and fallbacks
