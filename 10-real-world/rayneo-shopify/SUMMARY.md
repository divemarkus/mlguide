# RayNeo Cart Quantity Bug - Summary

**Date:** 2026-10-02  
**Severity:** HIGH  
**Status:** Confirmed

---

## Quick Summary

The "Buy Now" buttons on RayNeo product pages use **Shopify Universal Cart Page (UCP) permalinks** that replace the entire cart instead of adding items to it. This causes previously added items to be lost when clicking "Buy Now" on different products.

---

## Affected Products

| Product | Variant ID | Price |
|---------|------------|-------|
| RayNeo Sound Tube for GT / GT MAX | 52809489187103 | $19.00 |
| RayNeo Lens Shade for GT | 52809502425375 | $19.00 |

---

## The Bug

### What Happens

1. Add Sound Tube to cart → Cart has Sound Tube ×1 ✓
2. Navigate to Lens Shade page
3. Click "Buy Now" → **Cart now has ONLY Lens Shade ×1**
4. Sound Tube is **removed** from cart

### Why It Happens

The "Buy Now" button uses this URL pattern:
```
/cart/52809489187103:1
```

This is a **Shopify UCP permalink** that:
- Replaces the entire cart
- Removes all previous items
- Is designed for single-product checkout only

### Evidence

**Sound Tube page:**
```html
<link rel="buy" href="/cart/52809489187103:1?ucp/version=2026-08-25" />
<a href="/cart/52809489187103:1" data-sa-buy-now>Buy Now</a>
```

**Lens Shade page:**
```html
<link rel="buy" href="/cart/52809502425375:1?ucp/version=2026-08-25" />
<a href="/cart/52809502425375:1" data-sa-buy-now>Buy Now</a>
```

---

## Impact

- **Customers cannot add multiple products** to cart
- **Items disappear** when navigating between products
- **Lost sales** from frustrated users
- **Poor UX** requiring users to re-add items

---

## Solution

Replace UCP permalinks with proper cart addition:

**Option 1: AJAX Cart Addition**
```javascript
fetch('/cart/add.js', {
  method: 'POST',
  body: JSON.stringify({ id: VARIANT_ID, quantity: 1 })
});
```

**Option 2: Form Submission**
```html
<form action="/cart/add" method="post">
  <input type="hidden" name="id" value="VARIANT_ID" />
  <button type="submit">Buy Now</button>
</form>
```
