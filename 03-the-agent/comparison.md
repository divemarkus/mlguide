### Important distinctions

| Term                         | Meaning                                                                                       |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| Local model                  | The LLM performs inference on your own hardware.                                              |
| Local agent                  | The agent orchestration and tools run on your own hardware.                                   |
| Local web search             | Search infrastructure is self-hosted, such as SearXNG.                                        |
| Internet-enabled local agent | The agent and model run locally, but search requests or page retrieval use external services. |
| Fully local / offline        | Model, agent, tools and required data sources operate without external network access.        |
